# 🚀 Day 11: File Ownership (chown & chgrp)

## 👤 Understanding Ownership

Run `ls -l` to view file ownership.

`-rw-r--r-- 1 owner group size date filename`

- **Owner** → User who owns the file.
- **Group** → Group associated with the file.
